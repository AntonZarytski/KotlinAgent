# Примеры запросов с цепочками инструментов

## 🔍 Работа с кодом

### Поиск и чтение
```
Найди файл ClaudeClient.kt и покажи метод sendMessage
```
→ `search_files` → `read_file`

```
Покажи все файлы в папке services и содержимое TokenMetricsService
```
→ `list_directory` → `read_file`

```
Найди где используется McpResultsFilterService
```
→ `search_in_files` → `read_file` (несколько файлов)

### Анализ кода
```
Найди все TODO в проекте и покажи самые важные
```
→ `search_in_files("TODO")` → `read_file` (для каждого) → анализ

```
Покажи как работает сжатие истории
```
→ `search_files("HistoryCompressor")` → `read_file` → объяснение

## 📝 Создание тикетов

## 💡 Советы

### Явное указание последовательности
```
Сначала найди файл X, потом покажи функцию Y, затем создай тикет
```
→ Claude четко понимает последовательность

### Условная логика
```
Если в коде есть TODO - создай тикет, иначе просто покажи статистику
```
→ Claude сам решает на основе результатов

### Множественные действия
```
Для каждого файла с ошибкой создай отдельный тикет
```
→ Claude выполнит в цикле

## 🚫 Что НЕ работает

### Параллельные вызовы
```
❌ Одновременно проверь погоду И создай напоминание
```
→ Будет выполнено последовательно, не параллельно

### Слишком длинные цепочки
```
❌ Найди все файлы, прочитай каждый, проанализируй, создай тикеты для всех
```
→ Может превысить лимит итераций (20)

### Зацикливание
```
❌ Продолжай искать файлы пока не найдешь идеальный
```
→ Остановится после 7 одинаковых вызовов

## 🎓 Обучение агента

Агент учится на примерах. Чем больше вы используете цепочки, тем лучше он понимает паттерны:

**Хорошая практика:**
1. Начните с простых цепочек (2 инструмента)
2. Постепенно усложняйте
3. Давайте явные инструкции
4. Проверяйте результаты

**Плохая практика:**
1. Сразу сложные запросы
2. Неявные зависимости
3. Противоречивые инструкции
