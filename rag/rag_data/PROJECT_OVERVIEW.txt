1. ОБЗОР ПРОЕКТА
================================================================================

НАЗНАЧЕНИЕ:
KotlinAgent - это Kotlin-based AI chatbot платформа для взаимодействия с
Anthropic Claude API. Изначально написанная на Python Flask, полностью
переписана на Kotlin с использованием Ktor framework для повышения
производительности, типобезопасности и современных архитектурных паттернов.

КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ:
- Интеграция с Claude API (Claude 3.5 Sonnet) с поддержкой streaming
- RAG (Retrieval-Augmented Generation) - семантический поиск по документации
- MCP (Model Context Protocol) - расширяемая система инструментов
- Prompt Caching - экономия токенов до 90%
- Token Optimization - автоматическое сжатие истории, фильтрация tools
- Reminder System - планировщик задач с AI ответами и повторяющимися напоминаниями
- WebSocket Support - real-time обновления и streaming
- Multi-platform UI - Desktop (Compose), Web (HTML/JS), HTTP API

ТЕХНОЛОГИЧЕСКИЙ СТЕК:

Backend:
- Язык: Kotlin 2.2.20
- Framework: Ktor 3.x (async HTTP server)
- Database: SQLite с Exposed ORM 0.57.0
- HTTP Client: Ktor Client (OkHttp)
- Serialization: kotlinx.serialization
- Logging: Logback 1.5.12
- Build: Gradle 8.14

AI/ML:
- LLM: Claude 3.5 Sonnet (Anthropic API)
- Embeddings: Ollama (mxbai-embed-large, 768-dim vectors)
- Vector Search: Custom cosine similarity

External APIs:
- Anthropic Claude API - основной AI сервис
- Ollama - локальная генерация embeddings
- Open-Meteo - данные о погоде
- NOAA - солнечная активность

ТРЕБОВАНИЯ:
- Java 24 (Kotlin 2.2.20 не поддерживает Java 25)
- Gradle 8.14 (через wrapper)
- Ollama (для RAG embeddings)

Ключевые методы:

1. search() - поиск релевантных чанков

```kotlin
fun search(
    queryEmbedding: FloatArray,
    topK: Int = 5,
    minSimilarity: Double = 0.9
): List<SearchResult> {
    return transaction(ragDatabase) {
        val results = mutableListOf<SearchResult>()

        // Получаем все чанки из базы
        DocumentChunks.selectAll().forEach { row ->
            val chunkVector = row[DocumentChunks.vector].toFloatArray()

            // Вычисляем косинусное сходство
            val similarity = cosineSimilarity(queryEmbedding, chunkVector)

            if (similarity >= minSimilarity) {
                results.add(SearchResult(
                    docId = row[DocumentChunks.docId],
                    chunkIndex = row[DocumentChunks.chunkIndex],
                    text = row[DocumentChunks.text],
                    similarity = similarity
                ))
            }
        }

        // Сортируем по убыванию сходства и берем top-K
        results.sortedByDescending { it.similarity }.take(topK)
    }
}
```

2. cosineSimilarity() - вычисление сходства векторов

```kotlin
private fun cosineSimilarity(a: FloatArray, b: FloatArray): Double {
    require(a.size == b.size) { "Vectors must have same dimension" }

    var dotProduct = 0.0
    var normA = 0.0
    var normB = 0.0

    for (i in a.indices) {
        dotProduct += a[i] * b[i]
        normA += a[i] * a[i]
        normB += b[i] * b[i]
    }

    normA = sqrt(normA)
    normB = sqrt(normB)

    return if (normA > 0 && normB > 0) {
        dotProduct / (normA * normB)
    } else {
        0.0
    }
}
```

3. formatContext() - форматирование результатов в Markdown

```kotlin
fun formatContext(results: List<SearchResult>): String {
    if (results.isEmpty()) return ""

    return buildString {
        appendLine("# 📚 Контекст из документации")
        appendLine()
        appendLine("Найдено ${results.size} релевантных фрагментов")
        appendLine()

        results.forEachIndexed { index, result ->
            val fileName = result.docId.substringAfterLast('/')
            val similarityPercent = (result.similarity * 100).toInt()

            appendLine("## 📄 Фрагмент ${index + 1}: $fileName")
            appendLine("**Источник:** `${result.docId}`")
            appendLine("**Релевантность:** $similarityPercent%")
            appendLine()
            appendLine(result.text.trim())
            appendLine()
            appendLine("---")
            appendLine()
        }
    }
}
```

- Форматированный вывод с метаданными

data class TextChunk(
    val docId: String,
    val chunkIndex: Int,
    val text: String
)

companion object {
    fun splitIntoChunks(
        text: String,
        docId: String,
        chunkSize: Int = 500,
        overlap: Int = 50
    ): List<TextChunk> {
        val chunks = mutableListOf<TextChunk>()
        var startIndex = 0
        var chunkIndex = 0

        while (startIndex < text.length) {
            val endIndex = minOf(startIndex + chunkSize, text.length)
            val chunkText = text.substring(startIndex, endIndex)

            chunks.add(TextChunk(
                docId = docId,
                chunkIndex = chunkIndex++,
                text = chunkText.trim()
            ))

            // Сдвиг с учетом overlap
            startIndex += chunkSize - overlap
        }

        return chunks
    }
}
```

Параметры chunking:
- chunkSize: 500 символов (оптимально для embedding models)
- overlap: 50 символов (для сохранения контекста между чанками)

class OllamaClient(private val baseUrl: String) {
    private val httpClient = HttpClient(CIO) {
        install(ContentNegotiation) {
            json(Json {
                ignoreUnknownKeys = true
                isLenient = true
            })
        }
        install(HttpTimeout) {
            requestTimeoutMillis = 60_000
        }
    }

    suspend fun generateEmbedding(text: String): FloatArray {
        val response = httpClient.post("$baseUrl/api/embeddings") {
            contentType(ContentType.Application.Json)
            setBody(JsonObject(mapOf(
                "model" to JsonPrimitive("nomic-embed-text"),
                "prompt" to JsonPrimitive(text)
            )))
        }

        val jsonResponse = response.body<JsonObject>()
        val embedding = jsonResponse["embedding"]?.jsonArray
            ?: throw Exception("No embedding in response")

        return embedding.map { it.jsonPrimitive.float }.toFloatArray()
    }
}
```

Используемая модель: nomic-embed-text
- Размерность: 768
- Контекст: 8192 токенов

fun FloatArray.toByteArray(): ByteArray {
    val buffer = ByteBuffer.allocate(this.size * 4)
    buffer.order(ByteOrder.LITTLE_ENDIAN)
    this.forEach { buffer.putFloat(it) }
    return buffer.array()
}

fun ByteArray.toFloatArray(): FloatArray {
    val buffer = ByteBuffer.wrap(this)
    buffer.order(ByteOrder.LITTLE_ENDIAN)
    val floatArray = FloatArray(this.size / 4)
    for (i in floatArray.indices) {
        floatArray[i] = buffer.getFloat()
    }
    return floatArray
}

class WebSocketService {
    private val sessions = ConcurrentHashMap<String, MutableSet<WebSocketSession>>()

    // Регистрация нового соединения
    suspend fun registerSession(sessionId: String, wsSession: WebSocketSession) {
        sessions.computeIfAbsent(sessionId) {
            Collections.synchronizedSet(mutableSetOf())
        }.add(wsSession)

        logger.info("WebSocket registered for session: $sessionId")
    }

    // Удаление соединения
    suspend fun unregisterSession(sessionId: String, wsSession: WebSocketSession) {
        sessions[sessionId]?.remove(wsSession)
        if (sessions[sessionId]?.isEmpty() == true) {
            sessions.remove(sessionId)
        }

        logger.info("WebSocket unregistered for session: $sessionId")
    }

    // Отправка сообщения всем клиентам сессии
    suspend fun broadcastToSession(sessionId: String, message: WebSocketMessage) {
        val wsSessions = sessions[sessionId] ?: return

        val json = Json.encodeToString(message)

        wsSessions.forEach { wsSession ->
            try {
                wsSession.send(Frame.Text(json))
            } catch (e: Exception) {
                logger.error("Error sending WebSocket message", e)
            }
        }
    }
}

class LocalAgentManager {
    private val connections = ConcurrentHashMap<String, WebSocketSession>()
    private val pendingResults = ConcurrentHashMap<String, CompletableDeferred<String>>()

    // Обработка нового соединения от localAgentClient
    suspend fun handleConnection(wsSession: WebSocketSession) {
        val agentId = UUID.randomUUID().toString()
        connections[agentId] = wsSession

        try {
            for (frame in wsSession.incoming) {
                when (frame) {
                    is Frame.Text -> {
                        val message = Json.decodeFromString<RemoteToolResult>(
                            frame.readText()
                        )
                        handleToolResult(message)
                    }
                    else -> {}
                }
            }
        } finally {
            connections.remove(agentId)
        }
    }

    // Отправка команды на выполнение remote tool
    suspend fun sendCommand(sessionId: String, command: RemoteToolCommand) {
        val wsSession = connections.values.firstOrNull()
            ?: throw Exception("No local agent connected")

        val json = Json.encodeToString(command)
        wsSession.send(Frame.Text(json))

        // Создаем deferred для ожидания результата
        val key = "${sessionId}_${command.toolName}"
        pendingResults[key] = CompletableDeferred()
    }

    // Ожидание результата выполнения
    suspend fun awaitResult(sessionId: String, toolName: String): String {
        val key = "${sessionId}_${toolName}"
        val deferred = pendingResults[key]
            ?: throw Exception("No pending result for $key")

        return deferred.await()
    }

    // Обработка результата от localAgentClient
    private fun handleToolResult(result: RemoteToolResult) {
        val key = "${result.sessionId}_${result.toolName}"
        val deferred = pendingResults.remove(key)

        deferred?.complete(result.result)
    }
}

class TokenMetricsService {
    private val metrics = ConcurrentHashMap<String, TokenMetric>()

    data class TokenMetric(
        val timestamp: Long,
        val inputTokens: Int,
        val outputTokens: Int,
        val cacheCreationTokens: Int,
        val cacheReadTokens: Int,
        val model: String,
        val sessionId: String?
    )

    fun recordMetric(
        inputTokens: Int,
        outputTokens: Int,
        cacheCreationTokens: Int = 0,
        cacheReadTokens: Int = 0,
        model: String,
        sessionId: String? = null
    ) {
        val metric = TokenMetric(
            timestamp = System.currentTimeMillis(),
            inputTokens = inputTokens,
            outputTokens = outputTokens,
            cacheCreationTokens = cacheCreationTokens,
            cacheReadTokens = cacheReadTokens,
            model = model,
            sessionId = sessionId
        )

        metrics[UUID.randomUUID().toString()] = metric
    }

    fun getMetrics(
        startTime: Long? = null,
        endTime: Long? = null,
        sessionId: String? = null
    ): List<TokenMetric> {
        return metrics.values.filter { metric ->
            (startTime == null || metric.timestamp >= startTime) &&
            (endTime == null || metric.timestamp <= endTime) &&
            (sessionId == null || metric.sessionId == sessionId)
        }.sortedByDescending { it.timestamp }
    }

    fun getAggregatedStats(): TokenStats {
        val allMetrics = metrics.values

        return TokenStats(
            totalInputTokens = allMetrics.sumOf { it.inputTokens },
            totalOutputTokens = allMetrics.sumOf { it.outputTokens },
            totalCacheCreationTokens = allMetrics.sumOf { it.cacheCreationTokens },
            totalCacheReadTokens = allMetrics.sumOf { it.cacheReadTokens },
            requestCount = allMetrics.size,
            cacheHitRate = calculateCacheHitRate(allMetrics)
        )
    }

    private fun calculateCacheHitRate(metrics: Collection<TokenMetric>): Double {
        val totalCacheableTokens = metrics.sumOf {
            it.cacheCreationTokens + it.cacheReadTokens
        }

        return if (totalCacheableTokens > 0) {
            metrics.sumOf { it.cacheReadTokens }.toDouble() / totalCacheableTokens
        } else {
            0.0
        }
    }
}

        userMessage: String,

    ): List<JsonObject> {

            val toolName = tool["name"]?.jsonPrimitive?.content ?: return@filter false
            val keywords = toolKeywords[toolName] ?: return@filter true

            keywords.any { keyword -> messageLower.contains(keyword) }
        }
    }

================================================================================
10. TROUBLESHOOTING
================================================================================

ПРОБЛЕМА: "No embedding in response" при индексации

Решение:
1. Проверить, что Ollama запущен: `curl http://localhost:11434/api/tags`
2. Проверить, что модель загружена: `ollama list`
3. Загрузить модель: `ollama pull nomic-embed-text`

ПРОБЛЕМА: RAG не находит релевантные документы

Решение:
1. Проверить нормализацию векторов (должна быть одинаковая при индексации и поиске)
2. Снизить порог minSimilarity (например, с 0.9 до 0.3)
3. Увеличить topK (например, с 3 до 10)
4. Проверить, что документы действительно проиндексированы:
   ```sql
   sqlite3 rag_index.db "SELECT COUNT(*) FROM document_chunks;"
   ```

ПРОБЛЕМА: "Tool loop detected"

Решение:
1. Проверить логику tool - возможно, он возвращает некорректный результат
2. Увеличить LOOP_DETECTION_THRESHOLD в ClaudeClient.kt
3. Добавить более детальное описание в tool schema

ПРОБЛЕМА: Высокое потребление токенов

Решение:
1. Включить prompt caching (PromptCachingConfig.ENABLED = true)
2. Использовать динамическую фильтрацию tools (ToolsFilterService)
3. Сжимать историю чата (HistoryCompressor)
4. Проверить метрики: `curl http://localhost:8000/api/metrics/tokens`

ПРОБЛЕМА: WebSocket соединение разрывается

Решение:
1. Проверить настройки pingPeriod и timeout в ApplicationServer.kt
2. Проверить firewall/proxy настройки
3. Увеличить timeout на клиенте
