  - `source` - источник координат (user_provided/ip_geolocation/session)

- **Сообщение:** `"Ошибка get_weather_forecast: ${e.message}"`

  - Проблемы с сетью
  - Ошибка парсинга JSON-ответа
- **Решение:**
  - Проверить доступность https://api.open-meteo.com
  - Проверить корректность координат (latitude: -90..90, longitude: -180..180)
  - Проверить сетевое подключение
  - Проверить формат ответа API
