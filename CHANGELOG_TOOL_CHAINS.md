# Changelog: Поддержка цепочек MCP инструментов

## Дата: 2026-01-16

## Что добавлено

### 1. ToolChainMcp - легковесный планировщик цепочек

**Файл**: `remoteAgentServer/src/main/kotlin/com/claude/agent/llm/mcp/local/ToolChainMcp.kt`

**Функциональность**:
- Помогает Claude планировать последовательность вызовов инструментов
- Анализирует задачу и предлагает оптимальную последовательность
- Легковесный (в отличие от ActionPlannerMcp)
- Всегда включен по умолчанию

**Инструмент**: `plan_tool_chain`

**Когда использовать**:
- ✅ Нужно вызвать 2+ инструмента последовательно
- ✅ Результат одного инструмента нужен для другого
- ✅ Есть условная логика (если X, то Y)

**Когда НЕ использовать**:
- ❌ Одиночные вызовы инструментов
- ❌ Простые задачи без зависимостей

**Примеры**:
```
✅ "Найди файл config.kt и покажи его" -> search + read
✅ "Проверь погоду и напомни если дождь" -> weather + conditional reminder
❌ "Покажи погоду" -> просто вызови weather
```

## Как это работает

### Существующая функциональность (уже была)

ClaudeClient уже поддерживал последовательные вызовы через:
- `accumulatedToolResults` (ThreadLocal) - накопление результатов
- Цикл обработки `tool_use` блоков
- Передача результатов через `tool_result` в истории

### Что улучшено

1. **Явные инструкции** в системном промпте
2. **Легковесный планировщик** для помощи в сложных сценариях
3. **Документация** с примерами использования

## Примеры использования

### Автоматическое планирование (без ToolChainMcp)

```
Пользователь: Найди файл ClaudeClient.kt и покажи метод sendMessage

Claude:
1. git_repository.search_files("ClaudeClient.kt")
2. git_repository.read_file("путь/к/ClaudeClient.kt")
3. Текстовый ответ с содержимым метода
```

### С использованием ToolChainMcp

```
Пользователь: Проверь погоду и напомни если дождь

Claude:
1. plan_tool_chain({task: "...", available_tools: [...]})
2. weather.get_weather_forecast()
3. (если дождь) reminder.create_reminder({...})
4. Текстовый ответ
```

## Доступные комбинации

### Git Repository
- `search_files` → `read_file`
- `search_in_files` → `read_file` (множественные)
- `list_directory` → `read_file`

### Weather + Reminder
- `get_weather_forecast` → `create_reminder` (условно)

### Git + Support
- `search_in_files` → `create_ticket`
- `read_file` → `create_ticket`

### Help + Git
- `search_documentation` → `read_file`

## Ограничения

1. **Последовательность, не параллельность**: Инструменты вызываются один за другим
2. **Максимум 20 итераций**: Защита от бесконечных циклов
3. **Детекция зацикливания**: Остановка после 7 одинаковых вызовов подряд
4. **Обрезание результатов**: Большие результаты (>2000 символов) обрезаются

## Производительность

**Влияние на токены**:
- ToolChainMcp: ~100-300 токенов (легковесный)
- ActionPlannerMcp: ~500-1000 токенов (тяжелый, выключен)
- Экономия от умного планирования: ~200-500 токенов (меньше лишних вызовов)

**Итого**: Нейтральное или положительное влияние на расход токенов
