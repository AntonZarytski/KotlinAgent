# GitHub Integration для PR Review

## 📋 Обзор

KotlinAgent поддерживает автоматическую публикацию результатов AI ревью в GitHub Pull Requests через GitHub API.

## 🔑 Настройка GitHub Token

### Шаг 1: Создание Personal Access Token

1. Перейдите в GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Нажмите "Generate new token (classic)"
3. Настройте токен:
   - **Note**: `KotlinAgent PR Review`
   - **Expiration**: Выберите срок действия
   - **Scopes**: Выберите следующие разрешения:
     - ✅ `repo` (Full control of private repositories)
       - ✅ `repo:status` - Access commit status
       - ✅ `repo_deployment` - Access deployment status
       - ✅ `public_repo` - Access public repositories
       - ✅ `repo:invite` - Access repository invitations
     - ✅ `write:discussion` - Write team discussions (опционально)

4. Нажмите "Generate token"
5. **Скопируйте токен** - он будет показан только один раз!

### Шаг 2: Добавление токена в .env

Добавьте токен в файл `.env`:

```bash
# GitHub Integration
GITHUB_TOKEN=ghp_ваш_токен_здесь
```

**⚠️ ВАЖНО**: Не коммитьте `.env` файл в Git! Убедитесь, что он в `.gitignore`.

### Шаг 3: Перезапуск сервера

```bash
./gradlew :remoteAgentServer:run
```

При запуске вы должны увидеть:
```
GitHub integration enabled (token configured)
```

## 🚀 Использование

### Автоматическое ревью через Webhook

1. **Настройте GitHub Webhook** в вашем репозитории:
   - Settings → Webhooks → Add webhook
   - **Payload URL**: `https://your-server.com/api/pr-review/webhook`
   - **Content type**: `application/json`
   - **Events**: Выберите "Pull requests"
   - **Active**: ✅

2. **Создайте Pull Request** - ревью будет выполнено автоматически

3. **Результат**: Комментарий с AI ревью появится в PR автоматически

### Ручной запуск через API

```bash
curl -X POST https://your-server.com/api/pr-review \
  -H "Content-Type: application/json" \
  -d '{
    "branch": "feature/new-api",
    "baseBranch": "main",
    "prTitle": "Add new API endpoint",
    "enableRag": true
  }'
```

Комментарий будет опубликован автоматически, если в webhook payload есть информация о PR.

## 📊 Формат комментария

AI ревью публикуется в следующем формате:

```markdown
# 🤖 AI Code Review

## 📝 Summary
[Краткое описание изменений]

## 🔍 Detailed Analysis

### Critical Issues (🔴)
- **File**: `src/main/kotlin/Example.kt` (line 42)
  - **Issue**: Potential null pointer exception
  - **Suggestion**: Add null check before accessing property

### Warnings (⚠️)
- **File**: `src/test/kotlin/ExampleTest.kt` (line 15)
  - **Issue**: Missing test coverage for edge case
  - **Suggestion**: Add test for empty input

### Suggestions (💡)
- Consider using sealed class instead of enum
- Extract magic numbers to constants

## ✅ Compliance Checks
- [x] Code style follows Kotlin conventions
- [x] All tests pass
- [ ] Documentation updated

## 📚 Recommendations
1. Add KDoc comments for public API
2. Consider performance optimization in loop
3. Update README with new feature

---
*Generated by KotlinAgent AI Review*
```

## 🔧 Troubleshooting

### Комментарий не публикуется

**Проверьте логи сервера**:
```bash
tail -f logs/application.log | grep GitHub
```

**Возможные причины**:

1. **Токен не настроен**:
   ```
   ⚠️ GitHub integration disabled (GITHUB_TOKEN not set)
   ```
   → Добавьте `GITHUB_TOKEN` в `.env`

2. **Недостаточно прав**:
   ```
   ❌ Failed to post comment: 403 Forbidden
   ```
   → Проверьте scopes токена (нужен `repo`)

3. **Токен истек**:
   ```
   ❌ Failed to post comment: 401 Unauthorized
   ```
   → Создайте новый токен

4. **Неверный формат payload**:
   ```
   ⚠️ Missing repository info, cannot post to GitHub
   ```
   → Проверьте webhook payload

### Проверка работоспособности

**Тест GitHub API**:
```bash
curl -H "Authorization: Bearer $GITHUB_TOKEN" \
     https://api.github.com/user
```

Должен вернуть информацию о вашем GitHub аккаунте.

## 🔒 Безопасность

### Рекомендации

1. **Используйте минимальные права**: Выдавайте токену только необходимые scopes
2. **Ротация токенов**: Регулярно обновляйте токены
3. **Ограничьте срок действия**: Не создавайте токены без срока действия
4. **Храните безопасно**: Используйте secrets manager в production
5. **Не коммитьте**: Убедитесь что `.env` в `.gitignore`

### Production Deployment

Для production используйте переменные окружения вместо `.env`:

```bash
export GITHUB_TOKEN=ghp_your_token
export ANTHROPIC_API_KEY=sk-ant-your_key
./gradlew :remoteAgentServer:run
```

Или через systemd service:

```ini
[Service]
Environment="GITHUB_TOKEN=ghp_your_token"
Environment="ANTHROPIC_API_KEY=sk-ant-your_key"
ExecStart=/path/to/gradlew :remoteAgentServer:run
```
